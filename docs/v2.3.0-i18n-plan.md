# ASSH v2.3.0 国际化 (i18n) 计划

**版本**: v2.3.0  
**分支**: `dev/v2.3.0-phase-i18n`  
**开始日期**: 2026-06-15  
**状态**: 开发中  

## 一、目标

将 ASSH 的 CLI 输出消息进行国际化，支持中英双语，并提供翻译模板方便后续添加更多语言。

## 二、技术方案

### 2.1 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| i18n 库 | `github.com/nicksnyder/go-i18n` | Go 生态最成熟的 i18n 库 |
| 文件格式 | YAML | 结构清晰，易读易维护 |
| 键命名 | 点分层次 | 如 `cmd.server.add.success` |
| 语言切换 | 环境变量 | `LANG` / `LC_ALL` / `ASSH_LANG` |
| 默认语言 | 中文 (zh-CN) | 项目主要用户语言 |

### 2.2 目录结构

```
asshv2/
├── i18n/                          # 国际化资源目录
│   ├── zh-CN.yaml                 # 中文翻译
│   ├── en-US.yaml                 # 英文翻译
│   └── template.yaml              # 翻译模板（空值，供新语言参考）
├── internal/
│   └── i18n/
│       └── i18n.go                # i18n 初始化和工具函数
├── cmd/
│   └── app.go                     # 修改：使用翻译函数
└── ...
```

## 四、语言切换机制

### 4.1 优先级（从高到低）

1. `ASSH_LANG` 环境变量（专用）
2. `LC_ALL` 环境变量
3. `LANG` 环境变量
4. 默认：`zh-CN`

### 4.2 支持的语言代码

| 语言代码 | 语言 | 文件 |
|----------|------|------|
| `zh-CN` | 简体中文 | `i18n/zh-CN.yaml` |
| `en-US` | 英语 | `i18n/en-US.yaml` |

### 4.3 使用示例

```bash
# 使用英文
export ASSH_LANG=en_US.UTF-8
assh server ls

# 使用中文（默认）
unset ASSH_LANG
assh server ls

# 临时切换
ASSH_LANG=en_US.UTF-8 assh server ls
```

## 五、翻译文件格式

### 5.1 YAML 格式示例

```yaml
# zh-CN.yaml
common:
  success: "操作成功"
  error: "错误"
  cancelled: "已取消"

cmd:
  server:
    add:
      success: "服务器 {{.Name}} 已添加 (v{{.Version}})"
      error:
        name_required: "服务器名称不能为空"
        host_required: "必须指定 --host/-H 参数"
    set:
      success: "服务器 {{.Name}} 已更新 (v{{.Version}})"
      hint: "提示: 使用标志修改参数，如 --host, -p, -P, --remark"
    ls:
      empty: "没有找到服务器"
      header:
        group: "分组"
        name: "名称"
        host: "地址"
        ver: "版本"
        auth: "认证"
        remark: "备注"
```

### 5.2 模板变量

使用 `{{.Variable}}` 语法：

```yaml
# 英文
cmd.server.add.success: "Server {{.Name}} added (v{{.Version}})"

# 中文
cmd.server.add.success: "服务器 {{.Name}} 已添加 (v{{.Version}})"
```

## 六、代码变更示例

### 6.1 之前（硬编码）

```go
fmt.Printf("server %q added (v%d)\n", name, server.Version)
```

### 6.2 之后（使用 i18n）

```go
fmt.Println(i18n.T("cmd.server.add.success", map[string]interface{}{
    "Name":    name,
    "Version": server.Version,
}))
```

### 6.3 i18n 包接口

```go
package i18n

// T 返回翻译后的文本
func T(key string, args ...interface{}) string

// TWithLang 使用指定语言返回翻译
func TWithLang(lang, key string, args ...interface{}) string

// GetCurrentLang 返回当前语言
func GetCurrentLang() string

// SetLang 设置语言
func SetLang(lang string)

// Init 初始化 i18n
func Init(langDir string) error
```
