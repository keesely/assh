# CLI Commands

**目录**: `asshv2/cmd/`

## 功能

使用 `urfave/cli` 框架构建：

| 命令 | 功能 |
|------|------|
| `account` | 设置安全密码 |
| `ls/search` | 列出/搜索服务器 |
| `info` | 查看服务器详情 |
| `set` | 添加/修改服务器 |
| `rm` | 删除服务器 |
| `login` | 连接到服务器 |
| `bc` | 批量命令执行 |
| `push/pull` | 文件传输 |
| `keygen` | 生成 SSH 密钥 |
| `sync` | 云端同步（七牛云） |
| `export/import` | 导入导出配置 |
| `upgrade` | 检测更新 |
| `ping` | 检测服务器连通性 |
| `proxy/hostproxy/localproxy` | 代理功能 |
