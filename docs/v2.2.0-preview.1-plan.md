# v2.2.0-preview.1 版本规划

> 创建日期: 2026-06-14
> 状态: 🚧 开发中
> 分支: `dev/v2.2.0-experiment`

---

## 版本概述

**v2.2.0-preview.1** 是一个预览版本，专注于验证两个实验性功能：

1. **X1: AI 安全检查** — 通过 AI 大模型自动生成漏洞检测脚本
2. **X2: 虚拟命令投放与执行** — SSH 客户端本地命令扩展

本版本**不干扰**当前稳定版本 v2.1.2 的内容，所有实验性功能在此分支上独立开发。

## 版本目标

### 主要目标

1. **验证 X1 可行性**

2. **架构验证**
   - 模块划分是否合理
   - 接口设计是否清晰
   - 扩展性如何

## 技术约束

### 不干扰原则

1. **代码隔离**
   - 实验性功能代码放在独立目录
   - 不修改现有稳定代码
   - 使用条件编译或特性开关

2. **配置隔离**
   - 实验性配置独立文件
   - 不影响现有配置
   - 可选启用

3. **数据隔离**
   - 实验性数据独立存储
   - 不影响现有数据库
   - 可选清理

### 复用原则

1. **基础设施复用**
   - 复用 SSH 连接管理
   - 复用 SFTP 文件传输
   - 复用配置系统
   - 复用日志系统

2. **接口兼容**
   - 保持现有接口不变
   - 新接口独立定义
   - 避免破坏性变更

| 风险 | 影响 | 概率 | 缓解措施 |

## 验收标准

### X1 验收标准

```bash
# 1. AI 配置
assh security vuln-check --help
# 预期：显示帮助信息

# 2. CVE 检查
assh security vuln-check -s myserver "CVE-2024-3094"
# 预期：生成检测脚本并执行

# 3. 自由文本检查
assh security vuln-check -s myserver "检查 Log4j 漏洞"
# 预期：生成检测脚本并执行

# 4. 安全审查
assh security vuln-check -s myserver "rm -rf /"
# 预期：被安全审查阻止

# 5. 报告输出
ls ~/.assh/security/scripts/
# 预期：生成脚本和报告文件
```

### X2 验收标准

```bash
# 1. 启动 SSH 会话
assh login myserver

# 2. 测试 @push
@push ./local-file.txt /remote/path/
# 预期：文件上传成功

# 3. 测试 @pull
@pull /remote/file.txt ./local-path/
# 预期：文件下载成功

# 4. 测试 @help
@help
# 预期：显示命令列表

@help push
# 预期：显示 @push 帮助

# 5. 测试命令冲突
@push file  # 本地执行
push file   # 远程执行
# 预期：@push 本地，push 远程
```
