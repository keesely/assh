### 关键模式

1. **错误消息**: `fmt.Errorf("%s", i18n.T("key"))` — 避免 go vet 非常量格式字符串警告
2. **输出消息**: `fmt.Print(i18n.T("key"))` 或 `fmt.Printf("%s\n", i18n.T("key"))`
3. **模板变量**: `i18n.T("key", map[string]interface{}{"Name": name})`
4. **CLI 元数据**: `i18n.T("cmd.*.description")` 用于 Usage/Description
5. **Flag 描述**: `i18n.T("cmd.*.flag.*")` 用于 Flag Usage

### go vet 修复

Phase 2 完成后发现 72 个 `go vet` 警告（非非常量格式字符串），统一修复:
- `fmt.Errorf(i18n.T(...))` → `fmt.Errorf("%s", i18n.T(...))`
- `fmt.Printf(i18n.T(...))` → `fmt.Print(i18n.T(...))`
- `fmt.Fprintf(w, i18n.T(...))` → `fmt.Fprintf(w, "%s", i18n.T(...))`
