## 本次完成工作

### P7.1 — Proxy/PortForward/TunnelManager 接口定义

**文件**: `asshv2/asshc/port/proxy.go` (64 行)

定义三个接口：
- `Proxy` — SOCKS5 代理接口：`Start(client, localAddr)` / `Stop()` / `Addr()`
- `PortForward` — 端口转发接口：`ID()` / `Type()` / `LocalAddr()` / `RemoteAddr()` / `Start(client)` / `Stop()`
- `TunnelManager` — 隧道管理接口：`Add()` / `Remove()` / `Get()` / `List()` / `StopAll()`

设计决策：Start 方法接收 `*ssh.Client` 参数（非构造时传入），使 SSH 客户端生命周期由调用方（Service 层）管理。

### P7.2-a — SOCKS5 代理实现

**文件**: `asshv2/asshc/infra/proxy/socks5.go` (324 行)

遵循 RFC 1928 标准：
- **握手阶段**：读取客户端认证方法协商 → 选择 NO AUTH（0x00）
- **请求阶段**：仅支持 CONNECT（0x01）命令
- **地址类型**：支持 IPv4（0x01）、域名（0x03）、IPv6（0x04）
- **数据转发**：双向 io.Copy goroutine（`bidirectionalCopy`）
- **生命周期**：`acceptLoop` goroutine + `active` map 管理活跃连接
- **错误处理**：单个连接失败不影响其他连接，协议错误返回对应 SOCKS5 错误码

结构体：
```go
type SOCKS5Proxy struct {
    mu       sync.Mutex
    listener net.Listener
    addr     string
    active   map[net.Conn]struct{}
}
```

### P7.3-a/b — 端口转发实现（LocalForward + RemoteForward）

**文件**: `asshv2/asshc/infra/proxy/port.go` (261 行)

两种转发模式：
- **LocalForward（-L 等价）**：`net.Listen` 本地 → 新连接 `client.Dial` 通过 SSH → 双向拷贝
- **RemoteForward（-R 等价）**：`client.Listen`（发送 `tcpip-forward` 全局请求）→ 新连接 `net.Dial` 本地服务 → 双向拷贝
- ID 生成：`crypto/rand` 8 字节 → 16 字符十六进制
- 生命周期：`acceptLoop` goroutine + `active` map + `Stop()` 关闭监听器并清理所有活跃连接
