# ASSH DDD 架构设计文档

## 1. 架构概览

ASSH 项目采用**领域驱动设计（DDD）**结合**六边形架构（Hexagonal Architecture）**，也称为**端口-适配器模式（Ports and Adapters）**。

### 1.1 核心思想

```
┌─────────────────────────────────────────────────────────────┐
│                      用户界面层 (CLI)                        │
│                          cmd/                                │
└─────────────────────────────┬───────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      应用服务层 (Service)                    │
│                     service/ + port/                         │
│              （用例编排 + 接口定义）                          │
└─────────────────────────────┬───────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                        领域层 (Domain)                       │
│                        domain/                              │
│              （实体 + 值对象 + 领域错误）                    │
└─────────────────────────────────────────────────────────────┘
                              ▲
                              │
┌─────────────────────────────┴───────────────────────────────┐
│                    基础设施层 (Infrastructure)                │
│                         infra/                              │
│           （SQLite + SSH + SFTP + 代理 + 同步）              │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 分层职责

| 层级 | 包路径 | 职责 | 依赖方向 |
|------|--------|------|----------|
| **领域层** | `asshc/domain/` | 核心业务实体、值对象、领域错误 | 不依赖任何层 |
| **端口层** | `asshc/port/` | 业务接口定义（驱动端口 + 被驱动端口） | 依赖 domain |
| **服务层** | `asshc/service/` | 用例编排、业务流程协调 | 依赖 port + domain |
| **基础设施层** | `asshc/infra/` | 接口实现、外部系统集成 | 依赖 port + domain |
| **命令层** | `cmd/` | CLI 命令解析、用户交互 | 依赖 service |

### 1.3 依赖规则

```
┌──────────────────────────────────────────────────────────────┐
│                     依赖方向规则                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   cmd/ ──────────────► service/ ◄────────────── infra/       │
│                             │                      ▲         │
│                             ▼                      │         │
│                          port/ ────────────────────┘         │
│                             │                                │
│                             ▼                                │
│                          domain/                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**核心约束**：
- `domain/` 不依赖任何其他包
- `port/` 只依赖 `domain/`
- `service/` 只依赖 `port/` + `domain/`，不依赖 `infra/`
- `infra/` 实现 `port/` 定义的接口
- `cmd/` 只依赖 `service/`，通过 DI 获取实现

## 2. 二进制架构

项目构建为两个独立的可执行文件，共享同一套核心模块：

```
┌─────────────────────────────────────────────────────────────┐
│                    assh (主程序)                             │
│                    main.go                                  │
│   ┌───────────────────────────────────────────────────────┐ │
│   │ SSH 连接/管理 + SOCKS5 代理 + 隧道 + 服务器管理      │ │
│   │ • login/run/bc      - SSH 连接命令                    │ │
│   │ • server add/set/ls - 服务器配置管理                  │ │
│   │ • proxy             - SOCKS5 代理                     │ │
│   │ • tunnel            - SSH 隧道                        │ │
│   │ • keygen            - 密钥生成                        │ │
│   │ • health            - 健康检查                        │ │
│   │ • sync              - 云同步                          │ │
│   │ • mount             - 远程挂载                        │ │
│   └───────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
                              │
                              │ 共享核心层
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   assh-fs (文件系统工具)                     │
│                   cmd/fs/main.go                            │
│   ┌───────────────────────────────────────────────────────┐ │
│   │ 文件系统操作 (SFTP + 挂载)                            │ │
│   │ • push/pull         - 文件传输                        │ │
│   │ • <server>          - 交互式文件系统                  │ │
│   └───────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    共享核心层 (asshc/)                       │
│   ┌─────────────┬─────────────┬─────────────┬─────────────┐ │
│   │  domain/    │   port/     │  service/   │   infra/    │ │
│   │  领域实体   │  接口定义   │  用例编排   │  接口实现   │ │
│   └─────────────┴─────────────┴─────────────┴─────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

## 3. 领域模型概览

### 3.1 核心领域

```
┌─────────────────────────────────────────────────────────────┐
│                     核心领域模型                             │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐  │
│  │   Server     │    │     Auth     │    │   KnownServer│  │
│  │   (聚合根)   │◄───│   (值对象)   │    │   (实体)     │  │
│  └──────────────┘    └──────────────┘    └──────────────┘  │
│         │                                         │         │
│         ▼                                         ▼         │
│  ┌──────────────┐                         ┌──────────────┐  │
│  │  Changelog   │                         │   History    │  │
│  │  (领域事件)  │                         │   (记录)     │  │
│  └──────────────┘                         └──────────────┘  │
│                                                              │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐  │
│  │ CloudAccount │    │  SyncHistory │    │  UpdateInfo  │  │
│  │   (实体)     │    │   (实体)     │    │   (值对象)   │  │
│  └──────────────┘    └──────────────┘    └──────────────┘  │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 领域划分

| 领域 | 实体/值对象 | 说明 |
|------|-------------|------|
| **服务器管理** | Server, Auth, ChangelogEntry | 核心聚合，管理 SSH 服务器配置 |
| **连接历史** | KnownServer | 记录直连历史，支持密钥关联 |
| **云同步** | CloudAccount, SyncHistory | 云账户配置和同步历史 |
| **系统更新** | UpdateInfo, UpdatePlatform | 版本检查和更新管理 |

## 4. 端口设计

### 4.1 端口类型

```
┌─────────────────────────────────────────────────────────────┐
│                     端口分类                                 │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                 驱动端口 (Driving Ports)               │  │
│  │              （由外部调用，由服务层实现）              │  │
│  ├───────────────────────────────────────────────────────┤  │
│  │  • SSHConnector    - SSH 连接管理                      │  │
│  │  • FileTransfer    - 文件传输                          │  │
│  │  • ProxyService    - 代理服务                          │  │
│  │  • HealthChecker   - 健康检查                          │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                被驱动端口 (Driven Ports)               │  │
│  │              （由服务层调用，由基础设施实现）          │  │
│  ├───────────────────────────────────────────────────────┤  │
│  │  • ServerRepository  - 服务器存储                      │  │
│  │  • KnownServerRecorder - 连接历史存储                 │  │
│  │  • Cryptor           - 加解密服务                      │  │
│  │  • Syncer            - 云同步服务                      │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 主要端口列表

| 端口接口 | 所在包 | 职责 |
|----------|--------|------|
| `ServerRepository` | `port/` | 服务器配置 CRUD、版本管理 |
| `KnownServerRecorder` | `port/` | 直连历史记录 |
| `SSHConnector` | `port/` | SSH 连接建立和管理 |
| `SSHSession` | `port/` | SSH 会话操作（Shell/Run） |
| `Cryptor` | `port/` | 数据加解密（RSA/AES） |
| `FileTransfer` | `port/` | 文件传输（Push/Pull/List） |
| `TunnelManager` | `port/` | SSH 隧道管理 |
| `ProxyService` | `port/` | 代理服务（SOCKS5/HTTP） |
| `HealthChecker` | `port/` | 服务器健康检查 |
| `Syncer` | `port/` | 云同步服务 |
| `FileMounter` | `port/` | 远程文件系统挂载 |

### 6.2 依赖注入

依赖注入通过两个组合根实现：

```go
// main.go (assh 组合根)
func main() {
    // 1. 创建基础设施
    store := infra.NewSQLiteStore()
    sshConn := infra.NewSSHConnector()
    
    // 2. 注入到服务层
    serverService := service.NewServerService(store)
    connectService := service.NewConnectService(sshConn)
    
    // 3. 创建 CLI 应用
    app := cmd.NewApp(serverService, connectService)
    app.Run(os.Args)
}

// cmd/fs/main.go (assh-fs 组合根)
func main() {
    // 1. 共享初始化
    components := cmd.NewAppComponents()
    
    // 2. 创建文件系统专用服务
    transferService := service.NewTransferService(components.FileTransfer)
    
    // 3. 创建 CLI 应用
    app := cmd.NewFSApp(transferService)
    app.Run(os.Args)
}
```

## 7. 设计原则

### 7.1 SOLID 原则应用

| 原则 | 应用方式 |
|------|----------|
| **单一职责** | 每个服务只负责一个业务领域 |
| **开闭原则** | 通过接口扩展，不修改现有实现 |
| **里氏替换** | 所有接口实现可互换 |
| **接口隔离** | 端口接口小而专注 |
| **依赖倒置** | 服务依赖接口，不依赖实现 |

### 7.2 DDD 战术模式

| 模式 | 应用 |
|------|------|
| **实体** | Server, KnownServer, CloudAccount |
| **值对象** | Auth, UpdateInfo, ChangelogEntry |
| **聚合** | Server + Auth（通过 Server 聚合） |
| **仓储** | ServerRepository, KnownServerRecorder |
| **领域服务** | 无（业务逻辑在应用服务层） |
| **领域事件** | ChangelogEntry（变更记录） |
