# ASSH (An SSH) Client

我需要一个可以安全记录密码 / 快速登录 / 批量管理服务器的 SSH 客户端

## 核心需求

- 使用加密算法对服务器信息进行加密处理
- 可维护的服务器列表/支持群组管理 (add/mv/set/rm/ls/search/info)
- 支持独立密钥/密码登录服务器（优先使用密钥登录）
- 支持多种算法密钥（与 ssh-keygen 兼容）/ assh keygen 生成密钥
- 支持批量远程执行命令 / 支持按群组执行命令 (assh [group] -c [command])
- 支持同步数据文件到云端（安全加密）
- 支持构建端到端的加密通道（ssh 隧道）
- 支持反向代理（ssh 代理）/ 端口代理 / 域名代理 / sock5 通道代理
- 支持批量推送/拉取文件(push / pull)
- 支持远程文件系统挂载（webdav/sftp)
- 支持服务器健康检查 （heart）
- 支持服务器跳板机（ssh 跳板机）/ 基于 c/s 模式
- 支持虚拟命令映射

### 系统架构

使用 C/S 模式开发

#### Server 端（小端)：

使用端到端加密模式，基于 TLS /RTT-0 的通讯协议，负责响应 Client 的请求指令，包括但不限于：
- 虚拟指令执行
- 隧道/代理构建
- 跳板机服务
- 文件推送/接受 等

Server 端使用小端服务，由 client 端登录服务器释放，并主动监听用户指令；

#### Client 端(大端)：

主要工作端，实现ssh客户端功能，通过 ssh 登录服务器后，主动释放 server端 到服务器, 然后监听等待用户指令；
