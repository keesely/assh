### #C3 — RollbackTo() 明文密码写入 Changelog

**文件**: `asshv2/asshc/infra/store/server.go:377-421`  
**问题**: rollback 创建的 changelog 快照包含明文密码  
**修复方案**: 参考 `Set()` 实现，快照前加密密码

```go
// 修复前
snapshotJSON, _ := json.Marshal(restored) // ❌ 含明文

// 修复后
encrypted, _ := s.encryptPassword([]byte(restored.Auth.Password))
restored.Auth.Password = base64.StdEncoding.EncodeToString(encrypted)
snapshotJSON, _ := json.Marshal(restored) // ✅ 已加密
```

**预估**: 0.5h  
**风险**: 低 — 参考现有 Set() 实现

### #C1 — SFTP Shell 本地命令注入

**文件**: `asshv2/cmd/app.go:839-840, 1114-1122`  
**问题**: `!` 命令将用户输入直接传给 `exec.Command`  
**修复方案**: 白名单验证或路径沙箱

**方案选择**:
- **A. 白名单** — 限制可执行命令列表（推荐）
- **B. 沙箱** — 使用 `syscall.Chroot` 或容器
- **C. 禁用** — 移除 `!` 功能

**推荐方案 A**:
```go
var allowedLocalCmds = map[string]bool{
    "ls": true, "cat": true, "pwd": true, "echo": true,
    "grep": true, "head": true, "tail": true, "wc": true,
}

func handleLocalCmd(args []string) error {
    if !allowedLocalCmds[args[0]] {
        return fmt.Errorf("command not allowed: %s", args[0])
    }
    cmd := exec.Command(args[0], args[1:]...)
    // ...
}
```

**预估**: 1h  
**风险**: 低 — 功能限制可能影响用户体验

### #C2 — Host Key 验证可被绕过

**文件**: `asshv2/asshc/infra/ssh/client.go:367-370`  
**问题**: `insecure_skip_hostkey` 选项可被攻击者利用  
**修复方案**: 加固选项验证

**方案选择**:
- **A. 移除选项** — 强制 Host Key 验证（最安全，但破坏兼容性）
- **B. 加固验证** — 要求用户确认 + 记录警告日志（推荐）
- **C. 环境变量** — 仅允许通过环境变量启用（降低攻击面）

**推荐方案 B**:
```go
if v, ok := skip.(bool); ok && v {
    log.Warn().Msg("⚠️ Host key verification disabled (insecure_skip_hostkey=true)")
    log.Warn().Msg("   This should only be used in trusted networks")
    return ssh.InsecureIgnoreHostKey()
}
```

**预估**: 1h  
**风险**: 低
