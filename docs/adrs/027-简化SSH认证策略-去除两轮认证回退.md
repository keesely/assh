# ADR-027: 简化 SSH 认证策略 — 去除两轮认证回退

## Status
accepted

## Date
2026-05-13

## Context

### 问题背景

当前的 SSH 连接实现（`asshc/infra/ssh/client.go`）包含两轮认证回退机制：

1. **第一轮**：尝试所有可用的认证方法组合（SSH Agent → 密钥文件 → 密码）
2. **如果密钥认证失败且密码可用**：进行第二轮 Password-only 回退

这种设计导致的问题：

1. **复杂度高**：需要维护 `hasKeyAndPassword` 检查和 fallback 配置
2. **连接时间过长**：密钥认证失败后再等待 Password-only 连接，总耗时可能达到 20 秒
3. **行为不可预测**：用户无法确定最终使用哪种认证方式
4. **调试困难**：两轮尝试增加了问题排查的复杂度

### 技术约束

- SSH 连接参数来自 `domain.Server` 配置
- 支持多种认证方式：SSH Agent、密钥文件、密码
- 需要保持与现有 `port.SSHConnector` 接口的兼容性

## Decision

### 决策内容

**移除两轮认证回退机制，改为通过显式参数指定认证方式。**

### 方案设计

1. **单次认证策略**：每次连接只尝试一种指定的认证方式
2. **认证方式参数**：通过 `ConnectWithAuthType` 或 `AuthType` 字段指定认证优先级
3. **优先级规则**：用户可通过配置指定认证方式的优先级顺序

### 接口变更

```go
// 认证方式常量
const (
    AuthTypeAuto    = "auto"    // 自动选择（默认：Agent → KeyFile → Password）
    AuthTypeKey     = "key"     // 仅密钥
    AuthTypePassword = "password" // 仅密码
    AuthTypeAny     = "any"     // 任意可用（Agent/KeyFile/Password 都尝试）
)

// Connector 新增方法
func (c *Connector) ConnectWithAuthType(server *domain.Server, authType string) (*ssh.Client, error)
```

### 认证方式选择逻辑

| authType | 认证方法 |
|-----------|---------|
| `auto` | 依次尝试：Agent → KeyFile → Password（第一个成功即返回） |
| `key` | 仅尝试：KeyFile → Agent（无密钥失败） |
| `password` | 仅尝试：Password |
| `any` | 尝试所有可用方法（第一个成功即返回） |

### 配置方式

通过服务器配置的 `Options["auth_type"]` 字段指定：

```json
{
    "name": "ali.Sg",
    "host": "8.214.50.32",
    "auth": {
        "key_file": "/path/to/key",
        "password": "xxx"
    },
    "options": {
        "auth_type": "key"
    }
}
```

## Consequences

### 正面影响

1. **连接时间可预测**：单次认证尝试，最多等待一次超时时间（默认 10s）
2. **实现简化**：移除 `hasKeyAndPassword` 和 fallback 逻辑
3. **用户可控**：用户可明确指定认证方式，避免行为不确定性
4. **易于调试**：认证失败原因清晰（只尝试了一种方式）

### 负面影响

1. **向后兼容**：现有配置默认使用 `auto`，行为与之前略有不同（不进行两轮尝试）
2. **迁移成本**：需要更新文档和用户引导

### 废弃内容

以下代码将被移除：

```go
// 删除 hasKeyAndPassword 方法
func (c *Connector) hasKeyAndPassword(server *domain.Server) bool

// 简化 Connect 方法，移除 fallback 逻辑
// Connect 方法将只尝试 authMethods 返回的认证方式，不再进行二次尝试
```

## Implementation Notes

1. 首先更新 `port.SSHConnector` 接口，添加 `AuthType` 常量
2. 修改 `Connector.Connect` 方法，添加 `authType` 参数
3. 简化 `authMethods` 方法，根据 `authType` 返回单种或多种认证方法
4. 移除 `hasKeyAndPassword` 方法
5. 更新 `cmd/connect.go` 添加 `--auth-type` 参数支持
6. 添加单元测试验证不同认证方式的行为
