# ADR-003: 依赖注入策略（构造器注入，组合根在 main.go）

## Status
accepted

## Date
2026-05-08

## Context
v2 需要解耦各层依赖，避免直接调用全局变量或单例。

## Decision
所有依赖通过构造器参数注入（NewXxxService(repo PortRepository, crypto PortCryptor)），main.go 作为组合根统一实例化所有 infra 实现并注入 service，service 再注入 cmd。

## Consequences
1. 依赖关系清晰可见
2. 单元测试可自由替换依赖（传入 mock）
3. 初始化代码集中在 main.go，配置复杂
4. 需编写大量构造器函数
