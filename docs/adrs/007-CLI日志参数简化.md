# ADR-007: CLI 日志参数简化：移除日志级别参数

## Status
accepted

## Date
2026-05-08

## Context
之前 CLI 有两个日志相关参数：--log 指定日志路径，-llv 指定日志级别。用户要求简化：只保留 --log 参数，去除 -llv 参数。

## Decision
1. 移除 -llv flag（cli.StringFlag）
2. 保留 --log flag 用于指定日志路径
3. 更新 beforeAction 移除对 logLevel 的处理
4. 日志路径优先级：CLI --log > config.GetLogPath() > /tmp/assh.log 默认值

## Consequences
1. 用户无法通过 CLI 设置日志级别（已改为全部输出）
2. 简化 CLI 界面，只有一个日志参数
3. 需更新文档说明参数变更
