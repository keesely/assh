# ADR-023: Bug 文件名规范 — xxx → BUG-XXX-标题.md

## Status

accepted

## Date

2026-05-10

## Context

项目早期 Bug 记录使用非标准名称格式（如 `xxx`），不便于识别和检索。随着 Bug 数量增加（现已 9 个），需要统一的文件命名规范。

现有 Bug 文件列表：
- `BUG-001-log模块Fatal-Panic测试导致进程退出.md`
- `BUG-002-lib-qiniu-getCfg不可达代码.md`
- `BUG-003-log级别过滤测试期望值颠倒.md`
- `BUG-004-顶层默认Action短参数未解析.md`
- `BUG-005-info不显示密码和密钥详情.md`
- `BUG-006-assh-fs-sftp-exit-immediately.md`
- `BUG-007-overwrite-flags-not-passed-to-infra.md`
- `BUG-008-resume-not-passed-to-infra.md`
- `BUG-009-compute-remote-sha256-stub.md`

## Decision

统一 Bug 文件命名规范为：

```
docs/bugs/BUG-XXX-简短描述.md
```

其中 `XXX` 为三位数字序号，`简短描述` 为英文或中文的短横线连接短语。

文件内部格式：

```markdown
# BUG-XXX: 标题

## Status
fixed/known/in-progress

## Date
YYYY-MM-DD

## Description
问题描述...

## Solution
修复方案...

## Affected Files
- file1.go
- file2.go
```

## Consequences

正面：文件名自描述，便于搜索和识别；与 ADR 文件的命名风格一致（`XXX-标题.md`）；Git 日志中可快速定位 Bug 修改。

负面：已存在的文件无需重命名，仅新文件遵循此规范。
