# ADR-015: ls 命令输出格式优化

## Status
accepted

## Date
2026-05-10

## Context
Phase 4 完成后，对比 v1 (assh/) 和 v2 (asshv2) 的 ls 命令输出视图发现以下差异：

1. **Remark 列**：v1 在 ls 中直接显示备注，v2 需通过 `info` 命令查看
2. **Host 列格式**：v2 将 User/Host/Port 拆为三列，v1 合并为 `user@host:port` 格式
3. **颜色样式**：v2 纯文本无颜色，v1 有颜色交替 + 空值灰色提示
4. **Auth 表达**：v2 独立 Auth 列优于 v1 的括号嵌入方式

经用户逐项确认，确定了统一的优化方案。

## Decision
ls 输出调整为 6 列，按以下顺序：

| # | 列名 | 说明 |
|:-:|:-----|:------|
| 1 | Group | 分组名 |
| 2 | Name | 服务器名 |
| 3 | Host | 格式 `user@host:port`（合并 User/Port/Host） |
| 4 | Ver | 版本号 |
| 5 | Auth | 认证方式（password/key/password+key/none） |
| 6 | Remark | 备注，自适应宽度，空值留空 |

**颜色方案**：按群组设色系 + 组内隔行亮度交替

删除 v2 之前独立的 User 和 Port 列，合并到 Host 列中。

## Consequences

### 正面
- 信息布局更紧凑，与 v1 用户习惯一致
- 颜色辅助快速识别群组归属
- Remark 字段 ls 中一览无余

### 负面
- User/Port 从独立列变为嵌入格式，不便于按端口筛选
- 可通过 `--search` 和 `--group` 参数弥补
