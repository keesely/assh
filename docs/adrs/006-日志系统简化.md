# ADR-006: 日志系统简化：移除双日志输出和级别限制

## Status
accepted

## Date
2026-05-08

## Context
之前实现了 dual log 输出（logger + errorLogger），日志级别通过 LogLevel 过滤。用户要求简化日志系统：取消双日志，移除级别限制，只保留单一日志输出。

## Decision
1. 移除 errorLogger，仅保留单一 logger
2. 移除日志级别过滤逻辑（删除 if level > 0 && level <= LogLevel 判断）
3. 移除 config/path.go 中的 ErrorLogPath 常量
4. 所有日志级别均输出，不做过滤
5. ERROR/PANIC/FATAL 仍然调用 logger.Error() 输出

## Consequences
1. 日志量会增加（所有级别都会输出）
2. 运维时无法通过日志级别过滤
3. 代码更简洁，减少维护成本
4. 需更新测试用例移除 level filtering 相关测试
